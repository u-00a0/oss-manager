# OSS Manager Desktop

**OSS Manager Desktop** 是一款现代化、跨平台的对象存储图形化管理客户端。它基于 **Tauri 2** 架构构建，将原生 Rust 的性能优势与 **React 19** 灵动的 Web 前端交互完美结合，提供类 VS Code 的专业级文件管理体验。

## 🌟 核心功能

### 1. 现代化界面与交互
*   **VS Code 风格布局**: 熟悉的 Activity Bar、Sidebar 和 Status Bar 布局，上手零门槛。
*   **高级标签页系统**:
    *   **拖拽排序**: 自由调整标签页顺序。
    *   **窗口拆分 (Tear-out)**: 将标签页拖出主窗口即可创建新的独立窗口。
    *   **窗口合并**: 支持将标签页在不同窗口间拖拽合并。
    *   **分屏浏览**: 支持在同一窗口内将编辑器拆分为多个窗格。
*   **全局搜索**: 标题栏集成搜索框 (Ctrl+F)，快速过滤当前 Bucket 内的文件与文件夹。

### 2. 深度集成的文件浏览器
*   **高效导航**: 面包屑路径栏支持点击跳转，并可切换为输入模式手动输入路径。
*   **多维视图**: 提供“列表”与“网格”两种布局模式。
*   **拖拽操作**: 
    *   **上传**: 从系统资源管理器拖拽文件至应用即可触发上传。
    *   **下载**: 支持右键下载或“另存为”。
*   **文件管理**:
    *   **重命名**: 支持右键菜单或 `F2` 快捷键重命名文件。
    *   **批量删除**: 支持多选后按 `Delete` 键批量删除，带安全确认。
    *   **复制/移动**: 支持跨 Bucket 甚至跨账号的文件复制与移动。

### 3. 文件预览与详情
*   **预览窗格**: 类似 Windows 资源管理器的侧边预览栏，展示文件缩略图、元数据（ETag, 大小, 修改时间）及路径。
*   **即时预览**: 
    *   **图片**: 支持 PNG, JPG, SVG, WebP 等主流格式直接预览。
    *   **文本/代码**: 内置编辑器组件，支持 5MB 以内的文本文件内容查看与语法高亮。

### 4. 智能通知与传输管理
*   **全局状态栏**: 实时显示当前目录对象数量、选中状态及后台任务摘要。
*   **通知中心**: 类 VS Code 的通知弹窗，支持进度条显示，可折叠查看历史记录。
*   **传输仪表盘**:
    *   **侧边栏视图**: 在左侧活动栏快速查看正在进行和已完成的任务。
    *   **详细视图**: 独立的仪表盘标签页，提供实时速度曲线图和详细任务列表。
    *   **断点续传**: 自动记录传输进度，应用重启后可恢复任务。

### 5. 高级配置管理
*   **侧边栏管理**: 独立的配置文件管理侧边栏。
*   **导入/导出**: 支持将配置导出为 JSON 文件进行备份或迁移，支持直接导入配置文件。
*   **快捷操作**: 鼠标悬停配置项即可快速进行导出或删除操作。
*   **多语言支持**: 内置中英文切换，配置自动保存。

## 🛠️ 开发者指南

### 环境要求
*   Node.js (v20+)
*   Rust (最新稳定版)
*   Tauri CLI: `npm install -g @tauri-apps/cli`

### 环境初始化

```bash
cd oss-desktop
npm install
```

### 进入开发模式

启动 Vite 开发服务器并同步开启 Tauri 调试窗口：

```bash
npm run tauri dev
```

### 打包发布

生成生产环境安装程序（Windows 生成 .exe，Linux 生成 .deb/.AppImage）：

```bash
npm run tauri build
```

## 🧩 技术栈选型

*   **前端框架**: React 19, TypeScript
*   **状态管理**: React Context + Hooks
*   **样式方案**: Tailwind CSS v4
*   **图标系统**: Lucide React
*   **UI 组件**: Radix UI (部分), dnd-kit (拖拽交互), Recharts (图表)
*   **跨平台引擎**: Tauri 2 (Rust)
